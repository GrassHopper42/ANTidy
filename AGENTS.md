# Agent Instructions

## Commit Convention

Use this format for all commits:

```text
<icon> <type>: <description>
```

Commit descriptions may be written in Korean when that matches the surrounding work.

| Icon | Type | Use |
| --- | --- | --- |
| ✨ | `feat` | New feature |
| 🐛 | `fix` | Bug fix |
| ♻️ | `refactor` | Refactoring |
| 📝 | `docs` | Documentation |
| 🎨 | `style` | UI/style |
| ✅ | `test` | Tests |
| 🗃️ | `db` | DB/migration |
| 🔧 | `chore` | Configuration or tooling |
| 🚀 | `perf` | Performance |
| 🔒 | `security` | Security |
| 🗑️ | `remove` | Removal |

When creating or amending commits, follow this convention unless the user explicitly asks for a different message.
